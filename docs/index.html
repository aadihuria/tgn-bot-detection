temporal graph network for coordinated inauthentic behavior detection

most bot detectors look at one account at a time and ask "does this look fake" — follower count, account age, profile photo. bot operators know exactly what those checks look for, so a well-made bot clears every one of them on its own. what's hard to fake is a group of accounts acting together, over and over. one cluster of "strangers" all following the same target within the same few hours could be coincidence — the same cluster doing it again the next week, and the week after, isn't. that repeated, synchronized behavior is what this project catches: one model that scores accounts by their pattern of activity over time instead of a frozen snapshot, and a second, separate tool that flags whole clusters whose timing is too tight to be organic.

about the numbers on this page

the two standard real-world datasets for this task (twibot-20 and twibot-22) both require emailing the dataset authors and waiting for manual approval, which hasn't come through yet. so everything above was measured on a synthetic dataset built for this project instead — a generator that creates realistic organic accounts (people connecting gradually, more active in the evening than at 4am) alongside bot clusters that activate in synchronized bursts and go dormant in between. bot accounts are deliberately given the same kind of profile stats as real ones, on purpose — the point of this project is that per-account checks shouldn't be enough to catch them, so the generator doesn't hand that signal to the model for free. only the group timing gives them away. a loader for the real twibot file format is already written and sitting in the repo, ready to swap in the moment access comes through. full writeup and source: github.com/aadihuria/tgn-bot-detection.
